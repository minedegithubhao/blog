保留下来的核心判断

  • 首页先回答“改造是否值得推进”。
  • 所有实验必须绑定 dataset version、pipeline version、eval set。
  • 高风险退化是 promote 前必须查看的证据。
  • Pipeline 和 Eval Set 都保留可复跑、可审计的版本语义。

刻意不做的方向

  • 不把在线聊天作为主入口。
  • 不做通用 DAG 画布。
  • 不把首页做成泛指标大盘。
  • 不把 Eval Set 降级成普通 case 表格。
